# DoseMate TV - Part B tvOS Prototype

## Concept

DoseMate TV is a family medicine dashboard for Apple TV. It extends the iOS DoseMate app idea into the living room so the whole household can see medicine schedules, urgent doses, and progress for each family member.

## Why tvOS

tvOS is suitable because Apple TV is a shared screen. A medicine reminder app on a phone helps one person, but a medicine dashboard on TV helps the whole family coordinate care.

## Target Audience

- Families caring for parents or grandparents
- Shared households where more than one person needs reminders
- Students and busy workers who want visible routine reminders
- Caregivers who need a quick daily overview

## Similar Existing Apps

- Medisafe: personal medicine reminders on mobile
- Apple Health: health tracking, but not focused on shared TV medicine routines
- Reminder apps: general reminders, but not designed for family medicine care

DoseMate TV is different because it uses the television as a shared family health board.

## Core Prototype Features

- Family member cards with progress
- tvOS focus-friendly large UI cards
- Daily medicine schedule
- Urgent dose highlighting
- Built-in pitch screen for viva explanation
- Apple TV remote friendly navigation

## Platform-Specific Features

- Large visual cards for TV distance viewing
- Focus-based interaction through Button and Card style
- Landscape-first layout
- Tab-style pitch navigation suitable for tvOS

## Build And Run

1. Open `DoseMateTV.xcodeproj` in Xcode.
2. Choose a tvOS simulator or Apple TV destination.
3. Press Run.

## Viva Explanation

This prototype demonstrates a marketable extension of the iOS medicine app. The iPhone app manages personal medicine data, while the tvOS prototype shows how the same idea can become a shared household care product.
